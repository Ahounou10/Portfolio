# Portfolio — Ahounou Yannick

Portfolio personnel présentant mon profil de développeur web junior, mes compétences, mes projets et mes moyens de contact.

## Aperçu

Le site est réalisé avec les technologies web fondamentales :

- **HTML5** pour la structure des pages ;
- **CSS3** pour la mise en page, le responsive design et les animations ;
- **JavaScript** pour les interactions.

## Fonctionnalités actuelles

- Navigation avec menu adapté aux petits écrans ;
- Présentation du profil et des compétences ;
- Galerie de projets avec liens vers les dépôts et les démonstrations ;
- Animations d'apparition et effet de texte dans l'accueil ;
- Aperçu agrandi des images des projets ;
- Section de contact avec liens externes.

## Lancer le projet en local

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/Ahounou10/Portfolio.git
   ```

2. Ouvrir le dossier du projet.
3. Ouvrir `index.html` dans un navigateur, ou utiliser l'extension Live Server de Visual Studio Code.

Aucune installation de dépendance n'est nécessaire pour la version actuelle.
